# Grocy pour Home Assistant

Grocy 4.6.0 - ERP beyond your fridge

## Installation

1. Ajoutez ce dépôt dans Home Assistant
2. Installez l'addon "Grocy"
3. Démarrez l'addon
4. Accédez à Grocy via le bouton "Ouvrir l'interface Web"

## Configuration

Les données sont stockées dans `/config/grocy/`

## Accès externe

Configurez Nginx Proxy Manager pour accéder à Grocy depuis l'extérieur.

## Identifiants par défaut

- Utilisateur : `admin`
- Mot de passe : `admin`

⚠️ Changez le mot de passe après la première connexion !
